This is the `starter` monorepo for the AdonisJS + React.

<critical>
- Prefer `pnpm` for dependency management and scripts.
- In Amp orbs, run pnpm commands with `mise exec -- corepack pnpm` to ensure the repository's Node and pnpm versions are used.
- Never manually modify files in `.adonisjs/`; they are generated by AdonisJS and updated by the framework.
</critical>

## Working Agreements

- Keep root guidance small and broadly applicable. Add detailed conventions to focused docs when they only apply to one area.
- Check package-level `AGENTS.md` files for guidance specific apps or packages.

## Repository Expectations

- Run `pnpm lint`, `pnpm format`, and `pnpm typecheck` before committing code.
- Use Conventional Commits for commit messages: `type(scope): short description`.
- Write commit subjects and bodies in English.
- Prefer scopes that match the touched feature or package, for example `fix(articles): ...`, `feat(auth): ...`, or `chore(design-system): ...`.

## Agent skills

Issues are tracked in GitHub Issues for `Memsbdm/starter`. See `docs/agents/issue-tracker.md`.
